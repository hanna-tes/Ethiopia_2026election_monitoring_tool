How We Identify Weaponized Language

📚

1. Lexicon Engine

Curated dictionary of {{ total_terms }} known ethnic slurs, violence incitement, and election interference terms in English and Amharic. Provides 100% precision for known high-risk keywords.

🤖

2. LLM Semantic Analysis

Advanced language model analyzes context and semantics to detect nuanced threats, coded language, and evolving slang that exact-match systems might miss.

🎯

3. Fine-Tuned Gemma Model

Custom-trained multiclass classifier using LoRA adapter on Gemma model. Specifically trained to detect 19 distinct categories of weaponized language in the Ethiopia election context.

Gemma Model Detection Categories:

🔴 Violence 🔴 Inciteful 🔴 Call for Action 🔴 Dehumanization 🟠 Extremism 🟠 Ethnic Slur 🟠 Misogynistic 🟠 Slur 🟡 Derogatory 🟡 Inflammatory 🟡 Gender Disinformation 🟡 Stereotype 🔵 Ethnicity 🔵 Xenophobia 🔵 Religion 🔵 Homophobic ⚪ Ancestry ⚪ Class ⚪ Structural

🔬 Methodology: Our hybrid approach combines rule-based precision with AI-powered contextual understanding. Each detection method votes on the classification, and we calculate a weighted confidence score to minimize false positives while catching sophisticated manipulation tactics. The Gemma model was specifically trained on Ethiopia election discourse to recognize these 19 distinct categories of harmful language.
